# Farhan Abdilah Ramadhan: Portfolio

My personal developer portfolio, built with Next.js. The skills section is an interactive 3D keyboard where every keycap is a skill.

## Features

- **Interactive 3D keyboard:** hover, tap, or press a key to explore a skill.
- **HTML skills grid fallback:** shown automatically when WebGL is unavailable or the 3D scene fails to load.
- **Experience section:** internship, student organization, and freelance work.
- **Light and dark mode.**
- **Responsive layout** for desktop and mobile.

## Tech Stack

| Layer | Technologies |
| --- | --- |
| Framework | Next.js, React, TypeScript |
| Styling | Tailwind CSS |
| Animation | GSAP, Framer Motion |
| 3D | Three.js, React Three Fiber |

## Getting Started

```bash
npm install
npm run dev
```

Then open <https://farhan-ramadhan.vercel.app/>.
